# daftar_al_hisab_updates

مستودع عام صغير يستضيف فقط ملف بيان التحديث (`docs/update_manifest.json`)
الخاص بتطبيق "دفتر الحساب"، عبر GitHub Pages.

الكود المصدري الفعلي للتطبيق محفوظ في مستودع خاص منفصل. هذا المستودع
موجود فقط ليبقى رابط فحص التحديثات داخل التطبيق قابلاً للوصول العام دون
الحاجة لجعل مستودع الكود نفسه عاماً.

رابط البيان المباشر:
`https://abw3laa.github.io/daftar_al_hisab_updates/update_manifest.json`
